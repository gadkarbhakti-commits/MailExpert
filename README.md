MailExpert – AI Email Reply Generator

MailExpert is an AI-powered web application that generates professional email replies based on the user's email content, preferred tone, and desired response length.

Technologies:

1)Python
2)FastAPI
3)HTML
4)CSS
5)JavaScript
6)Groq API
7)Llama 3.3 70B
8)Docker
9)AWS Elastic Beanstalk

Features:

Email input
Multiple tones
Multiple response lengths
AI-generated replies
Streaming AI response
Copy reply functionality
Responsive web interface
Cloud deployment
