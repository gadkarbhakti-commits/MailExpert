MailExpert – AI Email Reply Generator

MailExpert is an AI-powered web application that generates professional email replies based on the user's email content, preferred tone, and desired response length.

Technologies:

1)Python
2)FastAPI
3)HTML
4)CSS
5)JavaScript
6)Groq API
7)Llama 3.3 70B
8)Docker
9)AWS Elastic Beanstalk

Features:

1.Email input
2.Multiple tones
3.Multiple response lengths
4.AI-generated replies
5.Streaming AI response
6.Copy reply functionality
7.Responsive web interface
8.Cloud deployment
